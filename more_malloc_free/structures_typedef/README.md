# 0x0D. C - Structures, typedef

## Description
This project introduces structures and `typedef` in C programming. It covers how to define structures, instantiate them, access their members, and manage memory dynamically for structures.

## Files
* **dog.h**: Header file containing the definition of `struct dog`, `dog_t`, and function prototypes.
* **1-init_dog.c**: Function that initializes a variable of type `struct dog`.
* **2-print_dog.c**: Function that prints a `struct dog` (handles `NULL` values safely).
* **4-new_dog.c**: Function that creates a new dog, dynamically allocating memory for a copy of its name and owner.
* **5-free_dog.c**: Function that safely frees the memory allocated for a `dog_t` struct and its strings.
